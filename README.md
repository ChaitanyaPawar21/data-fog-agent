# Data Fog Agent

An agentic system that finds, explains, cleans and protects a company's scattered data.

The app, its README and the deployment guide are in [`data-fog-agent/`](data-fog-agent/README.md).
The other folders are notes: the build spec (`communicator/`), architecture write-up
(`architecture/`), working context (`context/`) and a log of problems solved along the way
(`interview/`).
